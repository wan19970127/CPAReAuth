CPA ReAuth Helper 0.1.0

用法
1. 在 Chrome 116+ 的扩展管理页面开启开发者模式，选择“加载已解压的扩展程序”，选中本目录。
2. 打开 CPA-Manager-Plus 的 `management.html` 账号页，点击扩展图标打开侧边栏，再点“扫描当前管理页”。扩展会读取“运行状态 → 需要重新认证”列表，并自动配对页面和 CPA API。
3. 在侧边栏点击单个账号认证、认证所选或全部认证。“后台最小化认证”默认开启：无痕窗口默认最小化，检测到人机验证或需手动确认时自动弹出；密码页会优先点击邮箱验证码入口，不填写密码，也不会仅因出现密码框而弹窗。每个账号认证成功后，扩展会让管理页切到全部账号、刷新该账号额度，再恢复原筛选后继续下一个。
4. 在扩展设置填写 Cloud Mail 地址和管理员账号。
5. 首次保存时允许扩展访问 Cloud Mail 站点；并在扩展详情中开启“允许在无痕模式下运行”。

名单从 CPA-Manager-Plus 页面当前的 DOM 筛选结果读取；扩展不扫描 CPA 认证文件、不解码 token、不自行判断认证状态。队列进度、认证阶段和简化后的邮件诊断只显示在扩展侧边栏，不向认证网页注入提示横幅。任务队列在管理页刷新后仍由扩展后台继续执行。管理页需保持打开，以便逐账号刷新额度。批量认证前需关闭其他无痕窗口；名单账号须有邮箱。
